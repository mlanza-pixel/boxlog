❓ BoxLog Smart Guide

🌐 Netlify & Cloud Deployment
BoxLog runs natively as a PWA on Netlify with full HTTPS encryption. All data is saved safely in browser IndexedDB. Cross-device syncing is performed using 💾 Save File and 📂 Load File via iCloud Drive or Google Drive.
📱 Apple iOS & iPad Installation
Open BoxLog in native Safari on your iPhone or iPad, tap the Share icon, and select "Add to Home Screen" to install BoxLog as a standalone native app icon.
📷 iPad Camera & Voice Permissions
If camera or voice buttons are blocked in Safari: tap the aA settings icon on the left of Safari's address bar, choose Website Settings, and set Camera and Microphone to Allow.
🗄️ Database Tables & Real-Time Search
Tap 🗄️ View DB to search containers, items, projects, room assignments, insurance valuation manifests, and 3-tier moving truck loading sequences.
🎤 Voice Dictation & Serial Number OCR
Tap 🎤 Voice to dictate items hands-free (e.g. "3 porcelain plates 45 dollars"). Use 📷 AI Cam \(\rightarrow\) 🔍 Scan Serial OCR to extract model numbers and barcodes directly into descriptions.
💻 Local Python Sync Server
When running locally on a PC, execute python sync_server.py to enable multi-device automatic Wi-Fi delta sync across your home network.
